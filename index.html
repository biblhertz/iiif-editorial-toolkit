IIIF Editorial Toolkit

Self-contained, single-file HTML tools for creating, viewing, and managing IIIF manifests in academic and scholarly contexts. Developed at the Bibliotheca Hertziana – Max Planck Institute for Art History. Every tool below runs entirely in your browser — nothing is uploaded, nothing is installed.

Source on GitHub Documentation

Manifest Generation

IIIF Manifest Generator

The main tool. Five tabs: Individual Images, Comparison Layouts, Layer Alignment, Manifest Library, and Validation & Testing.

src/generator/iiif_generator.html

OpenSeadragon Generator

Simplified single-canvas compositions optimized for OpenSeadragon. Good for quick manifests and teaching materials.

src/openseadragon/osd_generator.html

Viewing & Testing

OpenSeadragon Viewer

High-performance viewing with multi-canvas navigation and automatic manifest type detection.

src/openseadragon/osd_viewer.html

Multi-Viewer Testing Tool

Test manifest compatibility across Mirador 3 and TheseusViewer, with manifest validation.

src/viewer/iiif_viewer.html

Manifest Dimension Updater

Batch-fetches real image dimensions from each info.json and fixes placeholder sizes in an existing manifest.

src/size_updater/IIIF_manifest_dimension_updater.html

Content State (Deep Links)

Content State Generator

Build a shareable deep link into a single region of an image, with a pan/zoom preview. Note: Mirador 3 does not support Content State — use the companion viewers below or TheseusViewer.

src/contentstate/iiif_contentstate_generator.html

Content State Test Viewer

Debug viewer for checking a generated Content State before publishing.

src/contentstate/iiif_viewer.html

Minimal Content State Viewer

Stripped-down viewer meant for embedding a Content State deep link in a published article.

src/contentstate/minimal_iiif_viewer.html

Editorial Workflow

JATS Alternatives Generator

Generates paired JATS <alternatives> graphic blocks (online IIIF + local archival reference) for article figures.

src/jats_alternatives/jats-alternatives-generator.html
XML → Manifest Suite is a Python pipeline (not a browser tool) that converts a JATS XML article directly into a manifest. See src/xml2manifest/ and its own readme.
